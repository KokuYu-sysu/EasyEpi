# EasyEpi M2 设计系统决策记录

> 确认日期：2026-07-18  
> 状态：已批准  
> 适用范围：M2 设计系统与可交互页面骨架

## 1. 实施顺序

- 继续采用已批准的纵向里程碑顺序。
- M2 先完成设计系统、主题、基础组件、路由和关键页面交互骨架。
- M2 验收后进入 M3，实施问卷模型、规则、Key、设计器和加密项目保存。

## 2. 交互深度

- M2 页面采用可交互原型，不采用静态占位页。
- 欢迎页、问卷设计页、录入页和管理页可实际导航并展示主要交互状态。
- M2 不保存真实问卷或答卷；演示内容不得伪装成已持久化业务数据。

## 3. 组件范围

M2 实现完整核心组件集：

- Button
- Input
- Textarea
- Select
- Checkbox
- Radio
- Modal
- ConfirmDialog
- Toast
- Progress
- EmptyState
- Skeleton
- Badge
- Tooltip

组件必须具备一致的尺寸、状态、焦点、错误反馈、禁用态和可访问名称。

## 4. UI 技术组合

- Tailwind CSS：设计 Token 与布局样式。
- Radix UI：无样式、可访问的交互原语。
- Lucide React：统一线性图标。
- React Router：渲染进程页面路由。
- Zustand：主题、字体和界面会话状态。
- 不在 M2 引入 Storybook；使用开发态组件展示页配合 Vitest 组件测试验收。

具体依赖版本在 M2 实施计划中根据现有 React 18、Vite 7 与 Electron 43 的 peer 兼容范围锁定为精确版本。

## 5. 页面与路由范围

M2 建立以下 9 类业务路由：

1. 欢迎页 / 项目选择页
2. 问卷设计页
3. EpiData 导入页
4. 单题录入页
5. 工作循环页
6. 管理员验证页
7. 数据管理页
8. 基线表页
9. 衍生变量页

欢迎页、问卷设计页、录入页和管理页实现完整交互骨架；其余页面使用统一应用框架、可导航标准骨架和明确的后续里程碑说明。

开发环境额外提供组件展示路由，生产构建不得从正常导航暴露该入口。

## 6. 主题与大字体

- 支持浅色、深色和跟随系统三种主题模式。
- 支持大字体模式。
- 顶栏提供主题与大字体快捷切换。
- 设置弹窗提供完整偏好选项。
- 偏好必须跨应用重启保存。

## 7. 偏好持久化

- 偏好由主进程保存到 Electron `userData/preferences.json`。
- 文件带明确的 schema 版本。
- 主进程执行运行时校验；损坏或未知字段不得导致应用无法启动。
- 保存使用临时文件、重新读取验证和原子替换。
- 渲染进程不得直接访问文件系统，也不使用 `localStorage` 作为事实来源。

## 8. 可访问性与动效

- 目标符合 WCAG 2.1 AA。
- 所有交互支持键盘操作和可见焦点。
- 表单控件具备可读标签、错误说明和合理的 ARIA 语义。
- 动效遵循 `prefers-reduced-motion`；用户请求减少动效时禁用非必要位移、缩放和弹跳。

## 9. 窗口适配

- 1024×700 保持所有功能可用，不产生阻断性横向溢出。
- 1366×768 为最佳布局基线。
- 更宽窗口可增强内容密度和并列布局。

## 10. 原型数据边界

- 使用明确标记的非敏感演示数据。
- 演示数据仅存在渲染进程内存中，应用重启后重置。
- 演示数据不得写入用户项目目录、`userData` 或业务文件。
- 真实项目创建、问卷保存、答卷录入和管理员认证均留给后续业务里程碑。

## 11. 版本与交付

- M2 应用版本升级为 `0.2.0`。
- M2 本地里程碑标签为 `v0.2.0-m2`。
- M2 生成 Windows x64 NSIS 安装版与便携版。
- 产物仍遵循已批准的未签名发行策略，并记录 SmartScreen 限制、文件大小和 SHA-256。
