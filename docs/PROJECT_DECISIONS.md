# EasyEpi 项目决策记录

> 更新日期：2026-07-18  
> 状态：已确认  
> 用途：记录产品落地过程中已确认的范围、默认值与交付约束，作为设计、实现和验收依据。

## 1. 产品与平台

- 产品名称：EasyEpi
- 发行者：KokuYu-EasyEpi Team
- 初始版本：0.1.0
- 目标平台：Windows 10/11 64 位
- 安装产物：NSIS 安装版 `.exe` 和免安装便携版 `.exe`
- macOS：当前版本不支持
- 应用图标：暂未提供，开发阶段使用临时图标，正式发布前替换

## 2. 界面与可用性

- 默认语言：简体中文
- 主题：支持浅色和深色
- 无障碍：支持大字体模式和键盘操作
- 最低目标分辨率：1366 × 768
- 首版不实现多语言

## 3. v1.0 功能范围

完整 v1.0 包含：

- 问卷设计与题目校验
- 条件规则与跳题逻辑
- 单一 Key 与复合 Key
- 项目和答卷加密保存
- 一问一屏录入
- 断点续录与工作循环
- 管理员数据管理
- CSV 导出及多选题编码
- 基线特征表
- EpiData `.qes` / `.rec` 导入
- 衍生变量公式
- 数据质量检查
- 双录入验证
- 自动备份与恢复

## 4. EpiData 兼容策略

- 当前未提供真实脱敏样本。
- 初期使用自建测试样本开发解析器。
- 在获得真实 `.qes` / `.rec` 样本前，真实格式兼容性属于明确的待实测风险。
- 后续样本统一放入 `tests/fixtures/epidata/`。
- 解析策略采用保守原则：无法可靠识别时报告错误，不猜测或静默修改数据。

## 5. 安全与数据存储

- 应用完全离线运行，不上传数据，不采集遥测。
- 使用管理员密码保护敏感数据。
- 创建项目时生成一次性恢复密钥。
- 无管理员密码或恢复密钥时不能解密数据，不提供绕过加密的找回方式。
- 每个调查项目存储在用户选择的独立项目目录。
- 项目目录包含加密项目文件、加密答卷文件和备份。
- 应用级配置存储在 Windows 用户数据目录。

## 6. 导出与统计

- CSV 使用 UTF-8 BOM，确保 Excel 直接打开中文不乱码。
- 多选题支持多分类、独热和哑变量三种编码方式。
- 基线表支持导出 CSV 和复制为 Markdown。
- 当前不导出 Excel、Word 或 PDF。

## 7. 更新、签名与发布

- 首版仅支持手动检查更新，不自动下载或安装。
- 当前没有 Windows 代码签名证书。
- 当前没有代码签名证书时，开发版和 v1.0 均允许生成未签名安装包与便携版。
- 未签名版本可能触发 Windows SmartScreen“未知发布者”提示，发布说明必须明确记录此限制。
- 将来获得证书后再接入签名流程，证书不是 v1.0 技术验收的阻塞条件。

## 8. Git 与交付方式

- 项目使用本地 Git 管理。
- 提交信息采用 Conventional Commits。
- 每个可验证任务单独提交，提交前运行对应测试或检查。
- 默认不创建或连接 GitHub 仓库，不自动推送远程。
- 每个里程碑保持可运行、可测试、可打包。
- 最终交付 NSIS 安装版 `.exe` 与便携版 `.exe`。

## 9. 性能与兼容性目标

- 支持 Windows 10/11 x64。
- 在 10,000 份答卷规模下，数据管理页面仍可流畅分页、筛选和浏览。
- 所有核心工作流在完全离线环境中可用。

## 10. 尚未确定但不阻塞开发的事项

- 正式应用 Logo 与 `.ico` 图标。
- Windows 代码签名证书。
- GitHub 或其他更新发布地址。
- 真实脱敏 EpiData `.qes` / `.rec` 兼容性样本。
