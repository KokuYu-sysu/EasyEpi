# EasyEpi 0.9.0

发布日期：2026-10-17。

## 修复

管理员数据管理表格原先将全部列平分在可视宽度内，题目多时会导致表头逐字换行并互相重叠。

现在表格总宽度随列数和拖动后的列宽增长，在表格内部横向滚动。长表头保持单行并显示省略号，鼠标悬停可查看完整题目；原有列宽拖动、排序、搜索及记录操作继续可用。

## 验证

- `pnpm check`：lint、类型检查、1450 项单元测试、覆盖率门槛及生产构建全部通过。
- Electron 端到端：15 项通过。新增回归覆盖 80 道长题目、空表、有记录、长答案、大字模式、窄窗口、列宽拖动，以及横向滚动到最后一题和编辑按钮。
- `pnpm build:win`：成功生成 Windows x64 安装版和便携版。
- 打包程序：便携版 6 项通过；解包程序 1 项通过，5 项仅针对便携版的测试按现有规则跳过。
- 本机发布测试设置 `NO_PROXY=127.0.0.1,localhost,::1`，避免代理拦截本机调试连接。
