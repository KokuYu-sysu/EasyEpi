# EasyEpi 1.0.0

发布日期：2026-10-18。

## 新增功能

在“问卷设计”页面点击“问卷导出”，可保存为空白 PDF 问卷或可编辑的 Word（`.docx`）文档。

- 固定长度题按设定长度绘制空白格，自由填空题保留下划线。
- 单选题使用圆形选项，多选题使用正方形选项。
- 受条件规则影响的题目前注明规则来源题号、触发条件和相应动作。
- Key 题号及题干加粗；中文、手动换行和选项顺序保留。
- 固定长度题每题最多导出 1000 格，整份问卷最多 10000 格；超出时提示调整，不截断内容。
- 自动修正保存文件的扩展名；修正后的最终文件已存在时再次确认覆盖。
