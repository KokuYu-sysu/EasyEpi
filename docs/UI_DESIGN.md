## 1. 设计原则与视觉规范

### 1.1 设计原则

| 原则 | 说明 |
|------|------|
| **极简专注** | 录入界面去除一切干扰元素，仅展示当前题目和进度。降低录入员的认知负荷 |
| **渐进披露** | 复杂功能（条件规则、基线表配置）默认折叠，按需展开。初级用户不被高级选项淹没 |
| **即时反馈** | 每个操作都有细腻的视觉反馈（微动效、过渡动画、触觉般的 Toast 提示） |
| **容错设计** | 所有破坏性操作需要确认；录入数据自动保存，防止意外丢失 |
| **无障碍优先** | 支持纯键盘操作、高对比度模式、大字体模式，符合 WCAG 2.1 AA 标准 |
| **现代美学** | 采用 2025+ 设计趋势：弥散阴影、毛玻璃效果、微妙的渐变、有机圆角与呼吸感留白 |

### 1.2 现代设计语言

本产品的视觉风格定位为 **"专业医疗 × 现代极简"**——在严谨的学术工具中注入消费级产品的精致感。

#### 1.2.1 视觉关键词

- **呼吸感**: 充足的留白空间（最小间距 8px 起，标准间距 16-24px），让界面"透气"
- **柔和深度**: 通过多层弥散阴影（而非单一硬阴影）表达 Z 轴层级
- **玻璃质感**: 关键模态与浮层使用 backdrop-blur 毛玻璃效果
- **有机圆角**: 卡片 `rounded-2xl`（16px），按钮 `rounded-xl`（12px），输入框 `rounded-lg`（8px）
- **流动过渡**: 200-400ms 的 ease-out/in-out 缓动，配合位移 + 透明度复合动画
- **微妙渐变**: 按钮、进度条、选中态使用细腻的线性渐变，避免纯色块的单调感

#### 1.2.2 材质层级

```
┌─────────────────────────────────┐
│ Z4: 模态框 / Toast / 下拉浮层   │ ← backdrop-blur-xl + shadow-2xl
├─────────────────────────────────┤
│ Z3: 弹出面板 / ConditionEditor  │ ← bg-white/90 + shadow-xl
├─────────────────────────────────┤
│ Z2: 卡片 / Table Row Hover      │ ← bg-white + shadow-md
├─────────────────────────────────┤
│ Z1: 导航栏 / 工具栏             │ ← bg-white/80 + border-b
├─────────────────────────────────┤
│ Z0: 页面底色                    │ ← bg-gradient-to-br from-slate-50 to-blue-50
└─────────────────────────────────┘
```

#### 1.2.3 圆角系统

| 圆角尺度 | 值 | 应用场景 |
|----------|-----|----------|
| `rounded-sm` | 4px | 小型徽章、键盘快捷键提示 |
| `rounded-lg` | 8px | 输入框、下拉菜单、表格单元格 |
| `rounded-xl` | 12px | 按钮、选项卡片、进度条 |
| `rounded-2xl` | 16px | 卡片容器、面板、录入题目卡片 |
| `rounded-3xl` | 24px | 大型模态框、特色功能卡片 |
| `rounded-full` | ∞ | 头像、Key 标记、单选/复选框、进度条轨道 |

### 1.4 字体系统

```css
/* 西文：Inter — 现代、高可读性、屏幕优化 */
/* 中文：系统默认中文字体栈，Microsoft YaHei / PingFang SC */
/* 代码：JetBrains Mono — 连字特性，公式清晰 */

--font-sans: 'Inter', 'SF Pro Display', system-ui, -apple-system,
             'Microsoft YaHei', 'PingFang SC', sans-serif;
--font-mono: 'JetBrains Mono', 'Fira Code', 'Consolas', 'Cascadia Code', monospace;
```

| 用途 | 字体族 | 大小 | 字重 | 行高 |
|------|--------|------|------|------|
| 页面标题 | Inter + 系统中文 | 28px | Bold (700) | 1.3 |
| 面板标题 | Inter + 系统中文 | 20px | Semibold (600) | 1.4 |
| 题目内容（录入模式） | 系统中文 | 22px | Medium (500) | 1.6 |
| 正文 | 系统中文 | 15px | Regular (400) | 1.6 |
| 辅助文字 | 系统中文 | 13px | Regular (400) | 1.5 |
| 小号标签 | Inter + 系统中文 | 11px | Medium (500) | 1.4 |
| 变量名/代码 | JetBrains Mono | 13px | Regular (400) | 1.5 |
| 数字/统计值 | Inter | 16px | Semibold (600) | 1.4 |

### 1.5 图标系统

使用 `lucide-react` 线性图标集，统一规格 **20×20px**，描边宽度 `stroke-width: 2`。关键图标：

| 图标 | 用途 | 图标 | 用途 |
|------|------|------|------|
| `clipboard-list` | 问卷设计 | `pencil` | 录入模式 |
| `key` | Key 标识符 | `link` | 条件规则关联 |
| `bar-chart-3` | 基线表 | `download` | 导出 |
| `lock` | 加密/密码 | `sqrt` | 衍生变量/公式 |
| `skip-forward` | 跳题 | `check-circle` | 完成 |
| `alert-triangle` | 警告 | `eye` / `eye-off` | 密码显隐 |
| `file-input` | 导入 EpiData | `columns-3` | 多选题编码 |
| `sigma` | 统计/公式 | `binary` | 独热/哑变量 |

## 6. 响应式与适配

### 6.1 窗口尺寸

| 模式 | 最小宽度 | 推荐宽度 | 说明 |
|------|----------|----------|------|
| 问卷设计 | 1024px | 1280px+ | 需要足够的水平空间展示题目列表和操作面板 |
| 录入模式 | 800px | 1024px | 单题模式信息密度低，支持较小窗口 |
| 管理后台 | 1024px | 1280px+ | 数据表格需要宽度 |
| 欢迎页 | 600px | 800px | 简单布局，可窄窗口 |

### 6.2 字体大小支持

- **标准模式** (默认): 题目 20px, 正文 14px, 辅助 12px
- **大字体模式** (可在设置中切换): 题目 24px, 正文 16px, 辅助 14px
- 切换大字体后，所有布局组件按比例放大，确保可读性

### 6.3 主题支持 (Phase 2+)

- **浅色主题**（默认）: 如上述设计，Slate 暖灰底色 + Indigo 主色，柔和护眼
- **深色主题**: Slate-900 底色 + 低对比柔和文字，适合长时间录入减少眼疲劳
- **系统跟随**: 自动跟随操作系统深浅色模式设置
- **高对比模式**: 为视觉障碍用户提供 WCAG AAA 级对比度

### 6.4 现代化视觉特征（Phase 1 实施清单）

以下特征在 MVP 阶段即融入所有页面，确保产品发布时具备现代化视觉质感：
