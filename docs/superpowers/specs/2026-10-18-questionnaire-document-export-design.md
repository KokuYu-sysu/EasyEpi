# 问卷 PDF / Word 导出设计（已确认）

## 目标与范围

基于当前 EasyEpi 0.9.0 新增空白问卷文档导出，提供 PDF 和真正可编辑的 Word `.docx`。导出当前已打开项目的问卷结构，包含标题、说明、全部题目与条件提示，不包含受访者记录、默认答案或衍生变量。

当前工作区已有文档和测试修改，本次实现应保留这些修改。

## 方案比较

1. 推荐：共用题号和条件说明生成逻辑，分别生成 PDF 与 DOCX。PDF 排版稳定，DOCX 可编辑；需要分别验证两种文件的布局。
2. 仅提供 PDF：实现较少，但缺少 Word 编辑能力。
3. 仅提供 DOCX：便于编辑，但用户打印或转 PDF 需要额外操作。

采用方案 1，两个格式使用相同的内容与排版规则，均可离线导出，不要求用户安装 Word。

## 入口与交互

- 用户于 2026-10-18 确认：入口放在“问卷设计”页面内，按钮名为“问卷导出”，点击打开格式选择对话框。
- 提供“导出 PDF”和“导出 Word”按钮，使用系统保存对话框选择文件位置；建议文件名为问卷名称，扩展名与格式一致。
- 未打开项目或问卷没有题目时禁用导出并显示原因。
- 导出期间禁用重复操作；取消保存不报错；失败时给出可理解的提示，成功后显示保存结果。
- 导出仅要求当前项目已打开并解锁，沿用问卷结构读取权限，无需额外管理员登录。

## 文档排版

- A4 纵向、适合黑白打印，中文字体，统一页边距。首页显示问卷标题及已有说明；按题目当前顺序生成连续题号。
- 固定长度填空：读取 `constraint.fixedLength`，每个字符对应一个空白格。格子用边框绘制，过长时换行，数量保持准确。
- 用户确认的资源限制：每题最多导出 1000 格，整份问卷最多 10000 格；超出时返回明确错误，不截断内容。
- 自由填空：显示供手写填写的下划线。
- 单选题：每个选项前显示空心圆形标记。
- 多选题：每个选项前显示空心正方形标记。“正方体选项”按纸面复选框解释。
- 数字范围题：下划线填写区，并标注已配置的最小值、最大值。
- 日期题：显示年、月、日填写区。
- Key 题：题号及题干加粗；普通题干使用常规字重，保持区别。
- 选项按原始顺序保留标签；不预选答案。长文本自动换行，尽量避免题干与其首个填写区或选项跨页分离；超出一页的长题允许分页。

## 条件规则

纸质问卷保留全部题目，不根据空白答案隐藏题目。在每个受规则影响的目标题目前逐条标注：条件来源题号、题目、比较条件、AND / OR 关系与动作。

例如：`【条件：当第 2 题“是否吸烟”等于“是”时，显示本题。】`

跳过和必填分别写为“跳过本题”和“本题必填”。多个规则逐条显示；复合条件保留“且 / 或”。选择题条件值优先转换为选项标签，避免仅显示内部编码。题号根据导出顺序映射，避免调整题目顺序后引用错误。

## 实现边界

- 新增问卷文档导出的请求与结果契约，通过 preload 白名单暴露给页面。
- 主进程校验 IPC 来源、请求、项目状态及格式，从当前项目读取问卷快照，并负责保存对话框和文件写入。
- 文档服务共用内容模型，集中处理题号、Key 标记、填写区和条件说明；PDF 与 DOCX 各自渲染。
- PDF 可使用 Electron 自带打印能力生成，导出页面为受控静态内容，题干及选项按文本处理。
- DOCX 使用标准 Office Open XML 文档格式，实际依赖选择在实现前核实；不得用 HTML 文件更改扩展名冒充 Word 文档。
- 临时渲染资源在成功、失败及取消时正确释放。
- 用户确认的文件名行为：扩展名不匹配时自动修正；修正后的最终文件已存在时，再次询问是否覆盖，取消则保留原文件。

## 验证与验收

- 内容测试：六种题型、固定格数量、Key 加粗、中文及特殊字符、题目顺序和选项顺序。
- 条件测试：show / skip / require、复合 AND / OR、多规则、选项编码转标签、重排后的题号引用。
- IPC 与页面测试：不可信来源、非法格式、未打开项目、空问卷、取消保存、失败提示与防重复点击。
- 实际生成 PDF 和 DOCX 样例，检查有效格式、中文、圆形和方形标记、格子及分页；对可用的文档渲染器生成页面图像进行目视核对。
- 运行相关单元测试、类型检查、lint 和生产构建；新增导航后更新受影响的路由与端到端验证。
