# EasyEpi 0.8.0 修订设计

## 目标

依据 `docs/REVISE.md` 完成 EasyEpi 0.8.0 的界面、导航和 AI 问卷设计优化，并交付 Windows x64 安装版与便携版。此次发布保持现有项目数据结构和 OpenAI Chat Completions 兼容接口不变。

## 范围

### 导航与页面

- 从桌面侧栏和紧凑导航中永久移除“工作循环”。
- 删除 `/work-session` 生产路由及不再使用的页面实现；未知或旧书签访问继续由现有兜底路由引导至欢迎页。
- 将所有面向用户的“单题录入”统一改为“问卷录入”，不修改内部稳定路径 `/entry` 和既有数据模型。
- 更新欢迎页、问卷设计页、EpiData 导入页及问卷录入页文案。对需求原文中的多余空格、未闭合引号和产品名称大小写进行排版规范化，不改变语义。

### 原生窗口菜单

- Electron 应用启动后设置空应用菜单，移除 Windows 窗口中的 File、Edit、View、Window 等原生菜单项。
- 不改变应用内部侧栏、紧凑导航、键盘焦点和页面路由。

### 字号选择

- 在现有标准字体/大字体切换入口增加明显的 `ab` 与 `AB` 字形提示。
- 控件继续提供完整的中文可访问名称、当前状态和键盘操作；不能仅凭字形或颜色表达状态。
- 保留现有字体偏好持久化和 `normal|large` 数据属性，不迁移用户设置。

### AI 学术检索增强

- 沿用用户当前配置的 OpenAI 兼容 AI 服务，不新增检索服务器、API Key 或服务商专属请求参数。
- 升级问卷生成系统提示词，明确要求模型在服务商支持时使用其内置 Web Search，先检索再设计问卷。
- 来源优先级为 PubMed、Web of Science、WHO、CDC、国家卫生健康委员会等学术数据库和权威机构；必要时允许补充高质量指南、系统综述和同行评议论文。
- 要求模型交叉核验关键结论，并在回答中提供题名或机构、年份及可访问链接/标识符。模型无法联网、没有找到可靠依据或对来源不确定时必须明确说明，禁止编造文献、DOI、PMID 或链接。
- 提示词明确区分“检索得到的证据”和“模型建议”。本地 Harness 继续负责结构化输出校验、安全边界和正式写入，检索内容不能绕过现有校验。
- 此方案只通过提示词请求服务商使用其已启用的搜索能力；EasyEpi 不承诺为未启用 Web Search 的模型强制开启工具。

## 版本与兼容性

- `package.json` 与锁文件版本更新为 `0.8.0`。
- 应用标识、项目文件格式、项目解锁、AI 配置和会话存储位置保持不变。
- AI 提示词版本及哈希按现有版本注册和迁移机制更新，旧会话继续遵循当前兼容策略。

## 测试与验收

- 单元测试验证生产路由及导航不再包含工作循环，旧 `/work-session` 不再进入业务页面。
- 页面测试验证新文案和“问卷录入”名称。
- 主进程测试验证应用菜单被移除。
- 主题/组件测试验证 `ab`/`AB` 字号标识、可访问名称、当前状态和偏好切换。
- AI Harness 测试验证新提示词版本、哈希、权威来源要求、引用约束及旧会话兼容行为。
- 运行 lint、TypeScript 类型检查、完整单元测试与覆盖率、生产构建，以及与本次改动相关的 Electron 端到端测试。
- 执行 Windows x64 打包，产物命名为 `EasyEpi-0.8.0-setup-x64.exe` 和 `EasyEpi-0.8.0-portable-x64.exe`，并核对文件存在、大小及版本信息。

## 非目标

- 不接入 EasyEpi 自建 PubMed/Web of Science 检索后端。
- 不加入特定服务商独有的 `tools`、`web_search` 或 Responses API 参数。
- 不重构问卷数据结构、AI 页面整体布局或现有权限模型。
- 不修改历史设计文档中对旧版本里程碑的记录。
