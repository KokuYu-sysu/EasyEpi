# EasyEpi M1 Engineering Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a secure, testable Electron + React foundation that launches on Windows and produces both an NSIS installer and portable `.exe`.

**Architecture:** Use electron-vite to build isolated main, preload, and renderer entry points. Establish one narrow, runtime-validated `system:ping` IPC path end to end; keep Electron primitives out of the renderer and isolate testable policies behind pure TypeScript functions.

**Tech Stack:** Electron 43.1.1, React 18.3.1, TypeScript 5.9.3, electron-vite 5.0.0, Vitest 4.1.10, Testing Library, Playwright Electron 1.61.1, ESLint 10.7.0, Prettier 3.9.5, electron-builder 26.15.3, pnpm 11.9.0.

---

## Scope and acceptance

M1 includes the secure desktop shell, typed IPC convention, a minimal Chinese welcome screen, local quality gates, Electron E2E smoke coverage, production build, NSIS x64 installer and portable x64 executable. It does not include Tailwind, routing, SQLite, encryption, questionnaires, data entry, or business services; those belong to later milestones.

M1 is accepted when all of the following succeed on Windows:

```powershell
pnpm install --frozen-lockfile
pnpm install:electron
pnpm lint
pnpm typecheck
pnpm test:unit
pnpm test:coverage
pnpm test:e2e
pnpm build
pnpm build:win
```

Expected artifacts include `release/EasyEpi-0.1.0-setup-x64.exe` and `release/EasyEpi-0.1.0-portable-x64.exe`. The package is unsigned by approved project policy.
