# Questionnaire document export implementation plan

**Goal:** Export the current blank questionnaire as PDF or editable DOCX from the designer's 问卷导出 button.

**Architecture:** Shared document model resolves ordered question numbers, answer areas and conditional instructions. Main process exports a snapshot through a validated IPC channel with its own native save dialog. Electron prints controlled HTML to PDF; docx creates native OOXML paragraphs, images and tables. The existing designer opens a format selection modal.

**Tech Stack:** TypeScript, Electron, React, Vitest, Playwright, docx.

## Constraints

- Keep existing worktree changes and the 0.9.0 application version.
- Entry is in the questionnaire designer, as explicitly chosen by the user.
- Export blank answer areas, all questions and no respondent data.
- Key titles are bold; circles for single choice and squares for multiple choice.
- Condition notes precede target questions and use the actual export numbering and option labels.
- Ask the user before resolving any outstanding product behavior; routine implementation follows the approved design.
