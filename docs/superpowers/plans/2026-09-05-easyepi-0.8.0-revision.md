# EasyEpi 0.8.0 Revision Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the approved EasyEpi 0.8.0 navigation, copy, menu, font indicator, and prompt-driven academic Web Search changes, then produce Windows installer and portable packages.

**Architecture:** Keep `/entry`, project data, IPC contracts, and the OpenAI-compatible Chat Completions transport stable. Remove the work-session feature at the renderer route/navigation boundary, express retrieval requirements solely in a versioned Harness system prompt, and preserve all existing provider negotiation and validation behavior.

**Tech Stack:** Electron 43, React 18, React Router 7, TypeScript 5.9, Vitest 4, Playwright 1.61, electron-vite 5, electron-builder 26, pnpm 11.

## Global Constraints

- Release version is exactly `0.8.0`.
- Produce Windows x64 NSIS and portable executables.
- Do not add a retrieval server, provider-specific request parameter, dependency, or credential.
- Preserve `/entry`, project file formats, AI configuration, session storage, local Harness validation, and administrator permissions.
- Preserve unrelated uncommitted changes already present in AI source and tests.
- Do not rewrite historical milestone or design documents that describe earlier releases.
